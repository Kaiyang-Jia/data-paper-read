# 部署说明

本目录保存当前服务器更新流程的可审阅代码，并不包含密钥、账户数据库、线上论文更新结果或向量索引。

`scheduled_update.py` 适用于现有服务器约定：项目位于 `/opt/datapaper`，Python 虚拟环境位于 `/opt/datapaper-venv`，账户和索引数据位于 `/var/lib/datapaper`，由 systemd 维护服务。脚本先在独立目录抓取、补充摘要和加工中文卡片，再复用未变化的向量并生成新索引，校验成功后切换目录和索引；出现异常时保留旧数据或回退。

生产服务器使用 Node 版 Next.js 运行网页。其运行时环境适配文件为 `backend.node.ts`；安装到 `site/app/lib/backend.ts` 后再构建。仓库默认的对应文件用于原有 Cloudflare 开发环境，二者不要混用。正式部署还需要自行配置 HTTPS、反向代理、持续运行、权限、账号数据备份和证书续期。现有服务器定时频率为北京时间每天 00:00 和 12:00；干净克隆不会自行创建此任务。

仓库不是线上数据备份。发布前请分别备份账号数据库、当前目录、索引及服务配置，密钥应另行保管。更新会调用外部服务，应核对服务可用性、限额和费用。
