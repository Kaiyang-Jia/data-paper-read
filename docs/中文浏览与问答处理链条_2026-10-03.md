# 中文浏览与问答处理链条

浏览和问答读取同一份论文目录。中文卡片在入库后批量加工并保存；问答时只生成针对当前问题的解释，不逐篇重新翻译。

2026-10-04 摘要补全：401 篇普通论文已补回原文摘要并更新中文卡片，现有 2,105 条摘要；剩余 10 条为更正公告。来源、流程和验证结果见 [摘要补全与来源验收](摘要补全与来源验收_2026-10-03.md)。

## 处理顺序

1. 从Crossref获取论文元数据与来源已提供的摘要，保留原始导出。
2. 统一DOI、清洗字段并去重；新增论文加入目录，重复记录只补已有空缺，不覆盖已有非空原文。
3. 对缺摘要的普通论文，先读取期刊官网明确的 Abstract 栏；失败后查询 Europe PMC 的摘要。两种来源均按 DOI 精确核对，保存来源网址、时间、内容指纹；不使用网页推广简介代替摘要。更正或撤稿公告单独标记，本轮不自动补。仍获取失败的条目保留缺失及尝试记录，下次可续接。
4. 为缺少当前加工版本的论文生成中文标题、中文介绍、中文主题标签和学科。摘要补回后原文指纹改变，对应中文卡片会重新加工。保存模型、处理时间、原文内容指纹和依据类型。
5. 逐篇保存加工结果，任务中断可续接。部分中文加工失败时不发布这轮中文目录；重新运行只补尚未完成的记录。
6. 全部成功后备份旧目录、发布中文目录，重建包含中文内容的语义索引；索引完成后才切换配置，旧索引保留。
7. 重启本地工作台，浏览页面、详情、导出与问答共用同一批中文卡片。

目录的中文卡片用于阅读和检索；问答推荐依据优先读取原文摘要，缺少摘要时使用原始标题，避免把前一轮模型解读当作原文证据。

## 日常操作

双击项目根目录“更新中文数据.bat”：获取最近14天论文，合并目录，补原文摘要，加工新增或原文发生变化的记录，重建索引。成功后双击“结束网页.bat”，等待窗口退出，再双击“启动网页.bat”。更新较久没运行时，使用下面的日期范围入口补齐遗漏时段。

```powershell
python -X utf8 -m research.update_catalog --from-date 2026-10-01 --to-date 2026-10-03
```

只补当前目录的原文摘要、中文加工和索引，不再次采集新论文：

```powershell
python -X utf8 -m research.update_catalog --skip-acquire
```

如摘要补全已经完成，只需要续接中文加工和索引，可再加 `--skip-abstracts`。单独诊断原文摘要：`python -X utf8 -m research.abstract_backfill --limit 5 --no-publish`；小批量检查只写检查点，不修改目录。正常更新会复用这些已核验成功的摘要。

该入口会调用外部模型服务。日常浏览不会触发加工任务。无须先恢复MariaDB；当前流程明确使用论文快照。

## 阅读边界

- 有摘要：中文介绍依据原始标题与摘要，可能包含数据内容、制作方法和应用线索；模型整理内容尚未人工复核。
- 没有摘要：中文介绍仅复述翻译后的标题，并明确说明数据内容、采集方式、样本规模和用途需核对原文。不会采用模型自由补出的介绍。
- 原有非空英文摘要、标题、作者、日期与DOI保持不变；只补原文摘要空缺。中文卡片不是全文翻译。
- 中文介绍和自动分类不是已核验的数据属性，不自动升级需求判断结果；人数、许可、数据语言等仍需原文或文件证据与复核。
- 同一篇的中文内容可以复用，原始标题、摘要或期刊字段变化会使加工指纹失效并重新加工。
- 更新目录之后需重启服务。索引失败时保留旧配置，修复后可使用“只补当前目录”入口续接。
- 定时执行频率尚未设置；一键更新入口已提供。
