# DataPaper 随手读

微信小程序是轻量阅读入口，与 Web 共用已加工的中文论文目录。四个入口：今日推荐、快速搜索、我的清单、项目更新。旧 AI 助手和登录页面不再注册为小程序页面，原文件和账户接口保留兼容。

- 每日推荐：北京时间当天，从最近120篇中按日期确定性轮换6篇；同一天、同一份目录顺序一致，不是个性化模型推荐，也不表示这些论文今天发表。
- 快速搜索：服务端中英文标题、摘要和主题检索，每页12篇；不下载完整目录。
- 收藏 / 稍后读：无需登录，本机保存论文快照；互相独立。读完可移出稍后读，收藏不受影响。
- 分享：卡片与详情页可分享给好友；详情使用稳定论文标识，接收者不依赖发送者本机缓存。详情配置朋友圈分享。
- 项目更新：来自 research/project_updates.json，每条包含日期和仓库来源，维护时添加确已完成的进展。

## 开发

1. 启动现有 Flask 后端（可以使用根目录启动网页.bat）。
2. 微信开发者工具导入 miniprogram 目录，使用测试号或正式 AppID。
3. 本机调试连接 config.js 中的 http://127.0.0.1:5000，允许不校验合法域名。
4. 真机和发布使用正式 AppID、可访问的 HTTPS 后端地址，并配置 request 合法域名。

小程序连接 Flask API，不是 site 的 Next.js 网页地址；后端目录来源遵循现有 DATAPAPER_CATALOG_SOURCE 配置。不新增爬虫或模型调用。

## 验证

仓库根目录：python -m unittest discover -s tests -p test_mobile_api.py -v
客户端行为：node --test miniprogram/tests/mobile.test.cjs

开发者工具还需检查 WXML 编译、触底加载、清单重启保留、断网推荐缓存、好友分享冷启动与朋友圈详情。游客 AppID 和 Node 模拟环境不能验证真实微信转发。

清单只保存在当前设备，不与 Web 浏览器清单或旧账户收藏自动同步。旧账户数据未删除。今日网络不可用时显示缓存日期，避免把旧推荐标为今天。
